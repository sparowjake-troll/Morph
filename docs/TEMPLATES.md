# Morph Template Gallery

Pre-built component templates for common web patterns. All templates use Tailwind CSS and shadcn/ui conventions.

## Heroes

| Variant | Description |
|---------|-------------|
| `centered` | Centered headline, subtext, and dual CTA buttons |
| `split` | Text on left, image on right (50/50 grid) |
| `video-bg` | Full-screen video background with overlay text |
| `animated` | Animated gradient background with floating orbs |
| `minimal` | Single large headline, no other elements |

**Location:** `src/generation/templates/heroes/`

## Interactive Patterns

Pre-built accessible patterns for common interactive elements:

| Pattern | Features |
|---------|----------|
| **Forms** | react-hook-form + zod validation, error messages, loading state |
| **Modals** | Focus trapping, ESC to close, backdrop click, portal rendering |
| **Tabs** | Keyboard navigation (Arrow keys, Home/End), ARIA roles |
| **Carousels** | Touch/swipe, autoplay, dot navigation, ARIA roledescription |
| **Accordions** | Single/multi expand, keyboard accessible, animated |
| **Dropdowns** | Keyboard navigation, outside click close, focus management |

**Location:** `src/generation/patterns/`
